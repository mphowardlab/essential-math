5.1 Background

Definition¶

An ordinary differential equation (ODE) contains one or more derivatives of an unknown function of one variable.

y′=cos⁡xy′′+9y=0x2y′′′y′+2exy4=(x2+2)y2\begin{align} &y' = \cos x \\ &y'' + 9y = 0 \\ &x^2 y''' y' + 2e^x y^4 = (x^2 + 2)y^2 \end{align}​y′=cosxy′′+9y=0x2y′′′y′+2exy4=(x2+2)y2​​
(1)

The order of an ODE is its highest derivative. The examples above are first order, second order, and third order ODEs, respectively, because their highest-order derivatives are y′y'y′, y′′y''y′′, and y′′′y'''y′′′. This chapter is focused only on first-order ODEs, but we will learn about second-order ODEs later.

First-order ODEs can be written most generally in implicit form:

F(x,y,y′)=0F(x, y, y') = 0F(x,y,y′)=0
(2)

where FFF is an arbitrary function of the independent variable xxx, the dependent variable (unknown function) yyy, and the derivative of the dependent variable y′y'y′. First-order ODEs can sometimes also be written in explicit form:

y′=f(x,y)y' = f(x, y)y′=f(x,y)
(3)

where fff is an arbitrary function of only yyy and y′y'y′. Not all first-order ODEs can be written in explicit form: you have to be able to isolate y′y'y′ from xxx and yyy.

General and particular solutions¶

The general solution to a first-order ODE will contain a constant ccc, so first-order ODEs have a family of solutions. For example, the first-order ODE

y′=xyy' = xyy′=xy
(4)

has the general solution:

y=cex2/2y = c e^{x^2 / 2}y=cex2/2
(5)

Different functions, all satisfying the ODE, can be created by choosing a value of ccc. We call each of these solutions a particular solution.

Initial value problems¶

Which particular solution is the “right” one? If we know the value of the function at a point, we can substitute this point into a general solution and solve for ccc. For example, let’s say we know that y=1y = 1y=1 when x=0x = 0x=0. Substituting into the general solution [Eq. (5)] gives:

1=y(0)=ce0=c1 = y(0) = c e^0 = c1=y(0)=ce0=c
(8)

so the particular solution is:

y=ex2/2y = e^{x^2/2}y=ex2/2
(9)

We call a point (x0,y0)(x_0, y_0)(x0​,y0​) where we know the value of the function an initial condition. It is often a starting point if the independent variable is time, but it does not have to be: the particular solution is only required to pass through this point. In this sense, you can think of the initial condition as being a piece of information you know about the function and can use to determine ccc.

A first-order ODE paired with an initial condition is called an initial value problem. Initial value problems are important for chemical engineering because they show how a dependent quantity evolves from a known point in time or space.

Direction field¶

Graphically, an explicit first-order ODE can be represented by a direction field (or slope field) showing the tangent to a particular solution at a point (x,y)(x,y)(x,y) because y′y'y′ represents the local rate of change. Starting from a point in the direction field and tracing a curve through it gives a particular solution, which corresponds to a certain value of ccc.
