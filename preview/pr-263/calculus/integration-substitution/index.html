1.7 Integration using substitution

When we know an integral

∫exd⁡ ⁣x=ex+c\int e^x \d{x} = e^x + c∫exdx=ex+c
(1)

we can evaluate related integrals like:

∫e−xd⁡ ⁣x=−e−x+c\int e^{-x} \d{x} = -e^{-x} + c∫e−xdx=−e−x+c
(2)

by making a substitution. Specifically, we define a new variable u, calculate its differential, and then replace both. For example, in this case, let u=−xu = -xu=−x. Then, d⁡ ⁣u=−d⁡ ⁣x\d{u} = -\d{x}du=−dx. Equivalently, x=−ux = -ux=−u and d⁡ ⁣x=−d⁡ ⁣u\d{x} = -\d{u}dx=−du so

∫e−xd⁡ ⁣x=−∫eud⁡ ⁣u=−eu+c=−e−x+c\int e^{-x} \d{x} = -\int e^u \d{u} = -e^u + c = -e^{-x} + c∫e−xdx=−∫eudu=−eu+c=−e−x+c
(3)

Let’s do a more complicated example:

∫xex2d⁡ ⁣x\int x e^{x^2} \d{x}∫xex2dx
(4)

Let u=x2u=x^2u=x2 so d⁡ ⁣u=2xd⁡ ⁣x\d{u} = 2x \d{x}du=2xdx. Then,

∫ex2xd⁡ ⁣x=∫eu⋅12d⁡ ⁣u=12eu+c\begin{align} \int e^{x^2} x\d{x} = \int e^u \cdot \frac{1}{2}\d{u} = \frac{1}{2} e^u + c \end{align}∫ex2xdx=∫eu⋅21​du=21​eu+c​​
(5)

Plugging u back in gives the final answer:

∫xex2d⁡ ⁣x=12ex2+c\int xe^{x^2} \d{x} = \frac{1}{2}e^{x^2} + c∫xex2dx=21​ex2+c
(6)
