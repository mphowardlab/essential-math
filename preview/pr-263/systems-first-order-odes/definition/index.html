6.1 Background

Definition¶

We know that an ODE contains one or more derivatives of an unknown function of one variable.

y′=6y+3\begin{align} y'&= 6y+3 \end{align}y′​=6y+3​​
(1)

A system of first order ODE incorporates n unknown variables and n expressions for those unknowns.

The general, explicit form of a system of first-order ODEs is:

y1′=f1(t,y1,⋯ ,yn)⋮yn′=fn(t,y1,⋯ ,yn)\begin{align} y_1' &= f_1(t, y_1, \cdots, y_n)\\ \vdots \\ y_n' &= f_n(t, y_1, \cdots, y_n) \end{align}y1′​⋮yn′​​=f1​(t,y1​,⋯,yn​)=fn​(t,y1​,⋯,yn​)​​
(2)

where t is the independent variable, (y1,⋯ ,yn)(y_1, \cdots, y_n)(y1​,⋯,yn​) are the n dependent variables, and (f1,⋯ ,fn)(f_1, \cdots, f_n)(f1​,⋯,fn​) are the n right-hand side functions of the n ODEs. We will notate this system more compactly using vectors

y′=f(t,y)\vv{y}' = \vv{f}(t, \vv{y})y′=f(t,y)
(3)

where yyy is the column vector of dependent variables, fff is the column vector of right-hand side functions, and y′\vv{y}'y′ is a shorthand for the column vector of first derivatives of all dependent variables.

As seen above, one ODE can feature multiple unknowns from within the system. Systems of ODE can incorporate other functions as part of their explicit definition.

Consider the following first order ODE in explicit form.

y′=6y+3\begin{align} y' &= 6y+3 \end{align}y′​=6y+3​​
(4)

We know how to solve this by choosing the appropriate method from Chapter 5. However, a problem occurs when a second ODE uses the unknown variable from the first, incorporating two unknowns into one ODE:

y′=6y+3g′=5y+18g−4\begin{align} y' &= 6y+3\\ g' &= 5y+18g-4 \end{align}y′g′​=6y+3=5y+18g−4​​
(5)

The expression for g′g'g′ features two unknowns, yyy and ggg. The ODE for g′g'g′ can not be solved with any previous techniques because it features two unknowns. Because of this, we have to use different techniques to solve this system of first order ODE. In this module, we will learn how to solve for both yyy and ggg simultaneously.

Successive Substitution¶

It is important to note that while multiple unknown variables can describe an explicit ODE, all unknowns are ultimately in terms of the single, independent variable. Consider Equation 5. We know yyy is a function of ttt. Hence it can be shown that

g′(g,y,t)=g′(g,y(t),t)\begin{align} g'(g,y,t) &= g'(g,y(t),t) \end{align}g′(g,y,t)​=g′(g,y(t),t)​​
(6)

so

g′(g,y(t),t)=g′(g,t)\begin{align} g'(g,y(t),t) &= g'(g,t) \end{align}g′(g,y(t),t)​=g′(g,t)​​
(7)

By the relationship above, we know that both yyy and ggg are in terms of one independent variable, ttt. If we can find the solution for one ODE, we can substitute it into the expression for the second ODE and evaluate. This is a valuable method of solving systems and is called successive substitution.

To illustrate this technique, we can observe a reaction network. Consider the following reaction:

A→k1B→k2C{\rm A} \xrightarrow{k_1} {\rm B} \xrightarrow{k_2} {\rm C}Ak1​​Bk2​​C
(8)

This network produces the following system of first order ODE.

d⁡ ⁣cAd⁡ ⁣t=−k1cAd⁡ ⁣cBd⁡ ⁣t=k1cA−k2cBd⁡ ⁣cCd⁡ ⁣t=k2cB\begin{align} \dd{}{c_{\rm A}}{t} &= -k_1 c_{\rm A} \\ \dd{}{c_{\rm B}}{t} &= k_1 c_{\rm A} - k_2 c_{\rm B} \\ \dd{}{c_{\rm C}}{t} &= k_2 c_{\rm B} \end{align}dtdcA​​dtdcB​​dtdcC​​​=−k1​cA​=k1​cA​−k2​cB​=k2​cB​​​
(9)

While it may not be obvious, we can solve this system through successive substitution. The derivative of cAc_AcA​ is a normal, separable first order ODE that can be solved using the techniques from unit 5. Once we have the solution to cAc_AcA​, f(t)f(t)f(t), we can substitute that expression into the ODE for cBc_BcB​. This will eliminate one of our unknowns, giving us one unknow, cBc_BcB​, and one independent variable, t.

d⁡ ⁣cBd⁡ ⁣t=k1f(t)−k2cB\begin{align} \dd{}{c_{\rm B}}{t} &= k_1 f(t) - k_2 c_{\rm B} \end{align}dtdcB​​​=k1​f(t)−k2​cB​​​
(10)

This one way in which successive substitution is a valuable tool for solving systems of ODE.
