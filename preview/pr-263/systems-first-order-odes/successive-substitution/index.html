6.2 Successive substitution

It is important to note that while multiple unknown variables can describe an explicit ODE, all unknowns are ultimately in terms of the single, independent variable. Consider Equation 5. We know yyy is a function of ttt. Hence it can be shown that

g′(g,y,t)=g′(g,y(t),t)\begin{align} g'(g,y,t) &= g'(g,y(t),t) \end{align}g′(g,y,t)​=g′(g,y(t),t)​​
(1)

so

g′(g,y(t),t)=g′(g,t)\begin{align} g'(g,y(t),t) &= g'(g,t) \end{align}g′(g,y(t),t)​=g′(g,t)​​
(2)

By the relationship above, we know that both yyy and ggg are in terms of one independent variable, ttt. If we can find the solution for one ODE, we can substitute it into the expression for the second ODE and evaluate. This is a valuable method of solving systems and is called successive substitution.

While it may not be obvious, we can solve this system through successive substitution. The derivative of cAc_AcA​ is a normal, separable first order ODE that can be solved using the techniques from unit 5. Once we have the solution to cAc_AcA​, f(t)f(t)f(t), we can substitute that expression into the ODE for cBc_BcB​. This will eliminate one of our unknowns, giving us one unknow, cBc_BcB​, and one independent variable, t.

d⁡ ⁣cBd⁡ ⁣t=k1f(t)−k2cB\begin{align} \dd{}{c_{\rm B}}{t} &= k_1 f(t) - k_2 c_{\rm B} \end{align}dtdcB​​​=k1​f(t)−k2​cB​​​
(3)

This one way in which successive substitution is a valuable tool for solving systems of ODE.

As previously discussed, systems of first order ODEs can include multiple unknown variables, making them ineligible to be solved through previous methods (i.e. integrating factor, La’place transform). Consider the reaction network problem from the background page, which has the following system of first order ODEs:

dcAdt=−k1cAdcBdt=k1cA−k2cBdcCdt=k2cB\begin{align} \frac{dc_{\rm A}}{dt} &= -k_1 c_{\rm A} \\ \frac{dc_{\rm B}}{dt} &= k_1 c_{\rm A} - k_2 c_{\rm B} \\ \frac{dc_{\rm C}}{dt} &= k_2 c_{\rm B} \end{align}dtdcA​​dtdcB​​dtdcC​​​=−k1​cA​=k1​cA​−k2​cB​=k2​cB​​​
(4)

The independent variable in this network is ttt, and there are three unknown variables, cAc_AcA​, cBc_BcB​, and cCc_CcC​. The derivative of cBc_BcB​ and cCc_CcC​ with respect to time includes two unknown variables, cAc_AcA​ and cBc_BcB​, and cBc_BcB​ and cCc_CcC​, respectively. The presence of two unknown variables in each of these expressions makes them impossible to solve with previous methods. Attempting to integrate the derivative of cCc_CcC​ as a separable function yields:

cC=k2cBt+C\begin{align} c_{\rm C} &= k_2 c_{\rm B} t +C \end{align}cC​​=k2​cB​t+C​​
(5)

The operation shown above is invalid because cBc_BcB​ is not a constant, it is an unknown function of t.

Despite the challenges in evaluating cBc_BcB​ and cCc_CcC​, what do you notice about the derivative expression for cAc_AcA​? It has an independent variable, t, and one unknown variable, cAc_AcA​. cAc_AcA​ matches the criteria for a linear first order differential ODE. This means we can solve for cAc_AcA​ as a separable function.
