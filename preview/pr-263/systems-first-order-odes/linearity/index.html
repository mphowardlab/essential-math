6.2 Linearity

A system of first-oder ODEs is linear if it can be written in the form:

y′=A(t)y+g(t)\vv{y}' = \vv{A}(t) \vv{y} + \vv{g}(t)y′=A(t)y+g(t)
(1)

Linear systems have unique solutions and special properties we will discuss later. An important special case is the homogeneous linear system with constant coefficients:

y′=Ay\vv{y}' = \vv{A} \vv{y}y′=Ay
(2)

Note that A is now constant and g=0\vv{g} = \vv{0}g=0. We will focus on solving these types of problems because they come up a lot in chemical engineering analysis (e.g., controls).

Systems of First Order ODEs with Successive Substitution¶

As previously discussed, systems of first order ODEs can include multiple unknown variables, making them ineligible to be solved through previous methods (i.e. integrating factor, La’place transform). Consider the reaction network problem from the background page.

A→k1B→k2C{\rm A} \xrightarrow{k_1} {\rm B} \xrightarrow{k_2} {\rm C}Ak1​​Bk2​​C
(3)

This network creates the following system of first order ODEs:

dcAdt=−k1cAdcBdt=k1cA−k2cBdcCdt=k2cB\begin{align} \frac{dc_{\rm A}}{dt} &= -k_1 c_{\rm A} \\ \frac{dc_{\rm B}}{dt} &= k_1 c_{\rm A} - k_2 c_{\rm B} \\ \frac{dc_{\rm C}}{dt} &= k_2 c_{\rm B} \end{align}dtdcA​​dtdcB​​dtdcC​​​=−k1​cA​=k1​cA​−k2​cB​=k2​cB​​​
(4)

The independent variable in this network is ttt, and there are three unknown variables, cAc_AcA​, cBc_BcB​, and cCc_CcC​. The derivative of cBc_BcB​ and cCc_CcC​ with respect to time includes two unknown variables, cAc_AcA​ and cBc_BcB​, and cBc_BcB​ and cCc_CcC​, respectively. The presence of two unknown variables in each of these expressions makes them impossible to solve with previous methods. Attempting to integrate the derivative of cCc_CcC​ as a separable function yields:

cC=k2cBt+C\begin{align} c_{\rm C} &= k_2 c_{\rm B} t +C \end{align}cC​​=k2​cB​t+C​​
(5)

The operation shown above is invalid because cBc_BcB​ is not a constant, it is an unknown function of t.

Despite the challenges in evaluating cBc_BcB​ and cCc_CcC​, what do you notice about the derivative expression for cAc_AcA​? It has an independent variable, t, and one unknown variable, cAc_AcA​. cAc_AcA​ matches the criteria for a linear first order differential ODE. This means we can solve for cAc_AcA​ as a separable function.
