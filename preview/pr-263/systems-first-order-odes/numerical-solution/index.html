6.4 Numerical solution methods

Systems of first-order ODEs can also be solved numerically using similar approaches as for single first-order ODEs, but now all dependent variables must be advanced simultaneously. The methods we use for single first-order ODES can be straightforwardly extended to systems using the explicit-form vector notation y′=f(t,y)\vv{y}' = \vv{f}(t, \vv{y})y′=f(t,y). For example, Euler’s method becomes:

y(t+Δt)≈y(t)+f(t,y)Δt\vv{y}(t+\Delta t) \approx \vv{y}(t) + \vv{f}(t, \vv{y}) \Delta ty(t+Δt)≈y(t)+f(t,y)Δt
(1)

We are “just” adding columns to our calculations!
