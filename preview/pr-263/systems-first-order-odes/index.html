Prerequisite knowledge¶

You should make sure you are comfortable with the following:

  • Integration techniques, including substitution, integration by parts, and partial fraction decomposition.

  • Evaluating limits.

  • Using matrices and vectors

  • Solving systems of linear equations and eigenvalue problems.
