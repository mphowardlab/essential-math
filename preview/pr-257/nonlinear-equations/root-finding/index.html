Fixed point iteration¶

If we want to numerically solve f(x)=0f(x) = 0f(x)=0, rearrange f(x)f(x)f(x) to get g(x)=xg(x) = xg(x)=x. Then, choose an inital guess x0x_0x0​ and iterate:

xn+1=g(xn)x_{n+1} = g(x_n)xn+1​=g(xn​)
(1)

until xn+1=xnx_{n+1} = x_nxn+1​=xn​ to the desired precision (error tolerance).

Bisection search¶

Intermediate value theorem

If f(x)f(x)f(x) is continuous on a≤x≤ba \le x \le ba≤x≤b, then it takes on all values from f(a)f(a)f(a) to f(b)f(b)f(b) at some point in that interval. As a result, if f(a)>0f(a) > 0f(a)>0 and f(b)<0f(b) < 0f(b)<0 (or vice versa), then f(x)=0f(x) = 0f(x)=0 somewhere in that interval!

We can apply this concept to find roots using the following procedure, called bisection search:

  1. Chose a0a_0a0​ and b0b_0b0​ so f(a)f(a)f(a) and f(b)f(b)f(b) have opposite signs.

  2. Starting at n=0n = 0n=0, evaluate f(xn)f(x_n)f(xn​) at the midpoint xn=(an+bn)/2x_n = (a_n + b_n)/2xn​=(an​+bn​)/2.

  3. If f(xn)≈0f(x_n) \approx 0f(xn​)≈0 a solution is found within desired precision. Otherwise, if f(an)f(a_n)f(an​) and f(xn)f(x_n)f(xn​) have the same sign, an+1=xna_{n+1} = x_nan+1​=xn​; else, bn+1=xnb_{n+1} = x_nbn+1​=xn​

  4. Increase nnn and repeat from step 2.

Newton-Raphson method¶

Although we cannot immediately solve the nonlinear equation f(x)=0f(x) = 0f(x)=0, we can first linearize it, then solve the linear problem.

f(x)≈f(x0)+f′(x0)(x−x0)=0x≈x0−f(x0)f′(x0)\begin{align} f(x) &\approx f(x_0) + f'(x_0)(x - x_0) = 0 \\ x &\approx x_0 - \frac{f(x_0)}{f'(x_0)} \end{align}f(x)x​≈f(x0​)+f′(x0​)(x−x0​)=0≈x0​−f′(x0​)f(x0​)​​​
(3)

Iterating this process gives the Newton-Raphson method of root finding

xn+1=xn−f(xn)f′(xn)x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}xn+1​=xn​−f′(xn​)f(xn​)​
(4)

The algorithm for the Newton-Raphson method is:

  1. Guess x0x_0x0​ and set n=0n = 0n=0.

  2. Compute f(xn)f(x_n)f(xn​) and f′(xn)f'(x_n)f′(xn​). If f(xn)f(x_n)f(xn​) is “close” to zero, stop.

  3. Update xn+1x_{n+1}xn+1​ using eq. (4) then return to step 2.

Note that this method can converge much more rapidly than the fixed-point or bisection methods. However, it will fail if f′(xn)=0f'(x_n) = 0f′(xn​)=0.
