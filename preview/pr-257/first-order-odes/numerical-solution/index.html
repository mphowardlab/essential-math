5.6 Numerical solution methods

Some ODEs are hard (or impossible!) to solve analytically... or maybe you just don’t want to! Numerical approximations to the solution can be very valuable in these cases.

Euler’s method

y(t+Δt)≈y(t)+f(t,y)Δty(t + \Delta t) \approx y(t) + f(t, y) \Delta ty(t+Δt)≈y(t)+f(t,y)Δt

The error increases as more timesteps are run due to accumulation of error. A smaller timestep typically produces a better solution, but at the cost of doing additional calculations. We will discuss next how the error depends on the step size.

Error in approximation¶

Because we are using truncated Taylor series, we accrue an error:

The error in a single step is O(Δt2)O(\Delta t^2)O(Δt2). This is called the local error. To cover a finite time t, t/Δtt/\Delta tt/Δt steps are required so the global (total) error is O(Δt)O(\Delta t)O(Δt). To improve accuracy, you should decrease Δt\Delta tΔt, but this takes more work. Some Δt\Delta tΔt will also totally fail! This is the field of numerical stability (not covered here).

Skill builder problems¶

  1. Solve y′=y+5sin⁡(2πt)y' = y + 5 \sin(2\pi t)y′=y+5sin(2πt) with y(0)=1y(0) = 1y(0)=1 using Euler’s method with two step sizes: Δt=0.1\Delta t = 0.1Δt=0.1 and 0.2 up to t=1t = 1t=1. Compare the accuracy of each to the analytical solution of the same ODE for y(1)y(1)y(1).

    The ODE is already in explicit form, so $f(t, y) = y + 5 \sin(2\pi t)$. To find the analytical solution, note that this is a linear first-order ODE \begin{equation} y' - y = 5 \sin(2\pi t) \end{equation} with $p = -1$ and $r = 5 \sin (2\pi t)$. The integrating factor and required integral are: \begin{align} F &= e^{\int p \d{t}} = e^{-t} \\ \int F r \d{t} &= 5 \int e^{-t} \sin(2\pi t) \d{t} \\ &= \frac{5 e^{-t}}{4\pi^2 + 1}\left[ -\sin(2\pi t) - 2\pi \cos(2\pi t)\right] \end{align} where the integral was evaluated using a table of integrals. Then, solve for *y* \begin{align} y &= \frac{1}{F} \left[\int F r \d{t} + c \right] \\ &= -\frac{5}{4\pi^2 + 1} \left(\sin(2\pi t) + 2\pi \cos(2\pi t)\right) + c e^{t} \end{align} Finally, apply the initial condition: \begin{equation} y(0) = \frac{-10 \pi}{4\pi^2 + 1} + c = 1 \end{equation} so \begin{equation} y = \left(1 + \frac{10\pi}{4\pi^2 + 1}\right) e^{t} - \frac{5}{4\pi^2 + 1} \left[\sin(2\pi t) + 2\pi \cos(2\pi t)\right] \end{equation} Evaluating this at $t = 1$ gives $y(1) = 4.052$. The absolute error is 0.369 for $\Delta t = 0.1$ and 0.730 for $\Delta t = 0.2$. Hence the error decreases by about a factor of 2 when $\Delta t$ is also decreased by a factor of 2.
