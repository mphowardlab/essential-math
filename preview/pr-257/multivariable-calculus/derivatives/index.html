2.1 Derivatives

A function f(x,y)f(x,y)f(x,y) has partial derivatives:

(∂f∂x)y=lim⁡h→0f(x+h,y)−f(x,y)h\td{}{f}{x}{y} = \lim_{h \to 0} \frac{f(x+h, y) - f(x, y)}{h}(∂x∂f​)y​=h→0lim​hf(x+h,y)−f(x,y)​
(1)

where x (in the denominator) indicates what is varied and y (outside the parentheses) indicates what is held constant.

The second partial derivative may be “repeated”

(∂2f∂x2)y=∂∂x[(∂f∂x)y]y\td{2}{f}{x}{y} = \pp{}{}{x}\left[ \td{}{f}{x}{y} \right]_y(∂x2∂2f​)y​=∂x∂​[(∂x∂f​)y​]y​
(2)

or “mixed”

∂2f∂x∂y=∂∂x[(∂f∂y)x]y\frac{\partial^2 f}{\partial x \partial y} = \pp{}{}{x}\left[ \td{}{f}{y}{x} \right]_y∂x∂y∂2f​=∂x∂​[(∂y∂f​)x​]y​
(3)

Mixed partial derivatives are read from right to left by convention.

Partial derivatives can be taken using the normal procedures for single-variable calculus if you treat the constant variables as such. For example, for the function f(x,y)=x2cos⁡yf(x,y) = x^2 \cos yf(x,y)=x2cosy,

  • The first partial derivative with respect to x (treating y as a constant) is

    (∂f∂x)y=2xcos⁡y\td{}{f}{x}{y} = 2 x \cos y(∂x∂f​)y​=2xcosy
    (4)

  • The second (repeated) partial derivative with respect to x (again, treating y as a constant) is

    (∂2f∂x2)y=∂∂x[(∂f∂x)y]y=∂∂x(2xcos⁡y)y=2cos⁡y\td{2}{f}{x}{y} = \pp{}{}{x}\left[ \td{}{f}{x}{y} \right]_y = \pp{}{}{x}\left( 2 x \cos y \right)_y = 2 \cos y(∂x2∂2f​)y​=∂x∂​[(∂x∂f​)y​]y​=∂x∂​(2xcosy)y​=2cosy
    (5)

  • The second (mixed) partial derivative with respect to x then y is

    ∂2f∂y∂x=∂∂y[(∂f∂x)y]x=∂∂y(2xcos⁡y)x=−2xsin⁡y\frac{\partial^2 f}{\partial y \partial x} = \pp{}{}{y}\left[ \td{}{f}{x}{y} \right]_x = \pp{}{}{y} \left( 2 x \cos y \right)_x = -2x \sin y∂y∂x∂2f​=∂y∂​[(∂x∂f​)y​]x​=∂y∂​(2xcosy)x​=−2xsiny
    (6)
Mixed second partial derivatives

If all the second partial derivatives of a multivariable function f are continuous, the mixed second partial derivatives are symmetric,

∂2f∂x∂y=∂2f∂y∂x\frac{\partial^2 f}{\partial x \partial y} = \frac{\partial^2 f}{\partial y \partial x}∂x∂y∂2f​=∂y∂x∂2f​
(7)

For the example function given above, the first partial derivative with respect to yyy is

(∂f∂x)y=−x2sin⁡y\td{}{f}{x}{y} = -x^2 \sin y(∂x∂f​)y​=−x2siny
(8)

So, the second (mixed) partial derivative with respect to y then x is

∂2f∂x∂y=∂∂x[(∂f∂y)x]y=∂∂x(−x2sin⁡y)y=−2xsin⁡y\frac{\partial^2 f}{\partial x \partial y} = \pp{}{}{x}\left[ \td{}{f}{y}{x} \right]_y = \pp{}{}{x} \left( -x^2 \sin y \right)_y = -2x \sin y∂x∂y∂2f​=∂x∂​[(∂y∂f​)x​]y​=∂x∂​(−x2siny)y​=−2xsiny
(9)
